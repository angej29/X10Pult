# X10 Пульт

Простий Android-застосунок для пилососа **Xiaomi Robot Vacuum X10+** (`dreame.vacuum.p2114a`):
керування через хмару Xiaomi без застосунку Xiaomi Home.

Код власний: протокол хмари Xiaomi (MIoT) і відкрита специфікація робота з miot-spec.org.
Коду Xiaomi в застосунку немає.

## Що вміє
- **Вхід** — сторінка входу Xiaomi відкривається всередині застосунку: пароль, капча, код із SMS чи пошти
  працюють як на сайті. Застосунок бере лише ключ входу (passToken) і сам отримує доступ до сервісу Mijia.
  Якщо Xiaomi відмовить, на екрані буде точний текст відповіді сервера (його можна скопіювати).
- **Пристрої** — пошук на всіх регіональних серверах Xiaomi (de, ru, sg, us, i2, cn, tw).
- **Пульт** — «Сухе прибирання» однією кнопкою (режим «Пилосос» + старт), Старт / Пауза / Стоп / На базу,
  «Знайти робота» (звук), режим прибирання, потужність всмоктування, подача води.
  Стан робота (статус, батарея, помилка, режим, площа й час) оновлюється кожні 5 секунд.

## Як отримати APK
Кожен push у `main` збирає APK у GitHub Actions; файл `X10Pult-N.apk` з'являється в Releases.
Під час першої збірки Actions створює ключ підпису `signing/x10pult.p12` і зберігає його в репозиторії
(тому репозиторій має бути **приватним**). Наступні версії ставляться поверх попередніх.

## Властивості робота (MIoT)
| Що | siid / piid чи aiid |
|---|---|
| Статус, помилка | 2/1, 2/2 |
| Батарея, заряджання | 3/1, 3/2 |
| Час і площа прибирання | 4/2, 4/3 |
| Потужність (0–3), вода (1–3) | 4/4, 4/5 |
| Режим прибирання (нижні біти: 0 пилосос, 1 миття, 2 разом) | 4/23 |
| Старт, пауза | дія 2/1, 2/2 |
| Стоп, на базу, знайти робота | дія 4/2, 3/1, 7/1 |

Якщо в режимі «Пилосос» робот усе одно миє підлогу, зніміть мопи: без них він тільки пилососить.
